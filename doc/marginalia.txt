==============================================================================
INTRODUCTION                                                     *marginalia*

Marginalia preserves Tree-sitter context by concealing irrelevant buffer lines
inside each attached window rather than mirroring context in an overlay.

==============================================================================
REQUIREMENTS                                        *marginalia-requirements*

Neovim 0.11 or newer and a parser for the active filetype are required. Actual
window-scoped rendering currently also requires Neovim's experimental
`nvim__ns_set()` API. Without it Marginalia disables concealment rather than
leaking namespace state into another window.

==============================================================================
SETUP                                                   *marginalia-setup*

>lua
    require('marginalia').setup({
        context = { max_depth = 4 },
        viewport = { scope = 'above_cursor' },
        render = { conceallevel = 2, priority = 200 },
    })
<

==============================================================================
COMMANDS                                             *marginalia-commands*

*:MarginaliaEnable*     Enable the current window.
*:MarginaliaDisable*    Disable the current window.
*:MarginaliaToggle*     Toggle the current window.
*:MarginaliaRefresh*    Recompute the current window.
*:MarginaliaDebug*      Print the current debug snapshot.
